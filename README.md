# ELDERVALE

A performance-first top-down 2D fantasy RPG for Android ARM64, built with Godot 4.5.1.

## Project goals
- Detailed dark-fantasy world with a top-down camera
- Responsive mobile controls
- Android-friendly rendering and performance budgets
- GitHub Actions validation and Android export

## Development status
Foundation setup in progress. The first milestone establishes the Godot project, a playable placeholder scene, and automated CI. Multiplayer systems will be introduced in later milestones.

## Current 3D visual pass
- Refined Warden sword-swing animation and subtle movement feedback.
- Added greaves/bracers and extra Ash Wolf muzzle/claw details.
- Added lightweight enemy paw gait and tail motion.
- Android ARM64 validation remains required through GitHub Actions before this pass is considered complete.
